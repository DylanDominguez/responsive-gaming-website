# 🎮 Responsive Gaming Website

Proyecto de una página web responsiva con temática de videojuegos, desarrollado como parte de mi aprendizaje en desarrollo frontend.

---

## 🧩 Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Flexbox
- Media Queries

---

## 📱 Características
- Diseño totalmente responsive
- Adaptado para dispositivos móviles, tablets y desktop
- Menú hamburguesa interactivo
- Interfaz moderna inspirada en videojuegos
- Layout flexible utilizando Flexbox

---

## 🎯 Objetivo del proyecto
Este proyecto fue desarrollado para practicar:
- Diseño responsive
- Creación de interfaces modernas
- Flexbox y organización de layouts
- Interacciones básicas con JavaScript
